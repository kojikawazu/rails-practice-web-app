## 非機能要件（割り切り方針）

トレーニング用途・ローカル単一ユーザー前提のため、本格的な非機能要件は対象外とする。割り切りの方針のみ記載する。

| 項目 | 方針 |
|---|---|
| パフォーマンス | 特別な要件は設けない。ローカル環境での動作を前提とする |
| スケーラビリティ | シングルユーザー利用を想定。スケール設計は対象外 |
| 可用性 | ローカル開発環境のみ。高可用性は不要 |
| 信頼性 | PostgreSQL を Docker で起動し、データは Docker Volume で永続化。バックアップは不要 |

## インフラ構成

- **PostgreSQL**: docker-compose で起動（ポート 5434）
- **MinIO**: docker-compose で起動（S3 互換ストレージ。ポート 9000=API / 9001=コンソール。フルスタック版の画像保存先）
- **Rails**: ローカル実行（Docker 外）
- Docker を使う理由: 現場での遭遇率が高い構成（ミドルウェアはコンテナ・アプリは手元で起動）を体験するため
