# 非機能仕様書（Non-Functional Specification）

## パフォーマンス

- トレーニング用途のため、特別なパフォーマンス要件は設けない
- ローカル環境での動作を前提とする

## スケーラビリティ

- シングルユーザー利用を想定
- スケーラビリティ設計は対象外

## 可用性

- ローカル開発環境のみ
- 高可用性は不要

## 信頼性

- PostgreSQL を使用（Docker コンテナで起動）
- データ永続化は Docker Volume で永続化、バックアップ不要

## インフラ構成

- **PostgreSQL**: docker-compose で起動（ポート 5434）
- **Rails**: ローカル実行（Docker 外）
- Docker を使う理由: 現場での遭遇率が高い構成を体験するため
