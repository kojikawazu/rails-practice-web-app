タスクCRUDフロー

プロジェクト詳細画面からのタスク作成・ステータス更新・削除のシーケンス

タスク作成（正常系）
プロジェクト詳細 → タスク作成フォーム → 保存 → 一覧に反映
ユーザー
ブラウザ (ERB)
TasksController
Task Model
PostgreSQL
1
「タスク追加」クリック
GET /projects/:id/tasks/new
2
フォーム表示
new アクション → ERB レンダリング
3
フォーム入力・送信
POST /projects/:id/tasks（title, status, start_date, end_date）
4
Strong Parameters
params.require(:task).permit(:title, :status, :start_date, :end_date)
5
バリデーション + 保存
project.tasks.build → save
✓ 保存成功
6
リダイレクト
redirect_to project_path + flash[:notice]
ステータス更新（正常系）
タスク編集画面でステータスを変更 → 保存
ユーザー
ブラウザ (ERB)
TasksController
Task Model
PostgreSQL
1
「編集」クリック
GET /projects/:id/tasks/:id/edit
2
編集フォーム表示
edit アクション → 既存値をフォームに設定
3
ステータス変更・送信
PATCH /projects/:id/tasks/:id（status: in_progress→completed）
4
更新
task.update(task_params)
✓ 更新成功
5
リダイレクト
redirect_to project_task_path + flash[:notice]
タスク削除（正常系）
確認ダイアログ → 削除 → プロジェクト詳細へリダイレクト
ユーザー
ブラウザ (ERB)
TasksController
Task Model
PostgreSQL
1
「削除」クリック
confirm ダイアログ表示
? ユーザーが「OK」を選択
2
削除リクエスト
DELETE /projects/:id/tasks/:id
3
レコード削除
task.destroy（物理削除）
✓ 削除成功
4
リダイレクト
redirect_to project_path + flash[:notice]

1
空のフォーム送信

2

3
エラー表示
render :new + @task.errors でエラーメッセージ表示
