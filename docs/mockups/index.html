データモデルヒント — 画面UIから導出されるテーブル候補
  • users: id, name, email, password_digest, created_at, updated_at
  • projects: id, title, description, user_id (FK→users), created_at, updated_at
  • tasks: id, title, status (enum: 0=not_started, 1=in_progress, 2=completed), due_date, project_id (FK→projects), created_at, updated_at
