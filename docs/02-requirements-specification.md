## 機能要件一覧

### Project 1: フルスタックRails（共通ドメイン）

| ID | 機能 | 説明 |
|----|------|------|
| F-001 | ユーザー登録 | name, email, password でアカウント作成 |
| F-002 | ログイン/ログアウト | セッションベースの認証（has_secure_password） |
| F-003 | プロジェクトCRUD | ユーザーに紐づくプロジェクトの作成・一覧・詳細・編集・削除 |
| F-004 | タスクCRUD | プロジェクトに紐づくタスクの作成・一覧・詳細・編集・削除 |
| F-005 | タスクステータス管理 | タスクの状態遷移（未着手→進行中→完了） |
| F-006 | バリデーション | 各モデルの入力値検証 |
| F-007 | フラッシュメッセージ | 操作結果のフィードバック表示 |
| F-008 | プロジェクト/タスク複製 | 既存レコードの値を引き継いだ新規作成フォームを開く（フルスタック版のみ・本体のみ複製、タイトルに「〜のコピー」を付与） |

### Project 2: Rails APIモード

| ID | 機能 | 説明 |
|----|------|------|
| A-001 | 上記 F-001〜F-006 のAPI版 | JSON形式でのリクエスト/レスポンス |
| A-002 | エラーレスポンス | 統一的なJSONエラーフォーマット |

## 受け入れ基準

| ID | 基準 |
|----|------|
| F-001 | ユーザーを新規作成し、DBに保存されること |
| F-002 | 正しい認証情報でログインでき、セッションが維持されること |
| F-003 | プロジェクトのCRUD全操作が画面から実行できること |
| F-004 | タスクのCRUD全操作が画面から実行できること |
| F-005 | ステータスを変更でき、変更が永続化されること |
| F-006 | 不正な入力に対してエラーメッセージが表示されること |
| F-007 | 操作成功/失敗時にフラッシュメッセージが表示されること |
| F-008 | 一覧/詳細から複製でき、複製元の値（タイトルは「〜のコピー」）が入った新規作成フォームが開くこと |

## 優先度

| 優先度 | 要件 |
|--------|------|
| Must | F-003（プロジェクトCRUD）、F-004（タスクCRUD）、F-006（バリデーション） |
| Should | F-001（ユーザー登録）、F-002（ログイン）、F-005（ステータス管理）、F-007（フラッシュ） |
| Could | A-001（API版）、A-002（エラーレスポンス）、F-008（複製） |
| Won't | デプロイ、CI/CD、複雑な権限管理 |
