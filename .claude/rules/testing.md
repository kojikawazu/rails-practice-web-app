# テスト方針

- **テスト必須**: 実装時はテストコードも必ず書く。
- **テストファースト推奨**: 可能な限りテストを先に書いてから実装する。
- **テストは独立**: 各テストは他のテストに依存しない。
- **テストデータ**: FactoryBot でテストデータを管理する。

## テストツール

| テスト種別 | ツール |
|-----------|--------|
| ユニットテスト / モデルテスト | RSpec + Shoulda Matchers |
| コントローラーテスト | RSpec + request specs |
| E2E テスト | RSpec + Capybara |
| スモークテスト | scripts/smoke-test.sh |
